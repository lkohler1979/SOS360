# SOS360

PWA de preparação familiar e sobrevivência outdoor, com API e painel administrativo planejado.

## Início

```bash
npm install
npm run dev:web
npm run dev:api
```

Web: http://localhost:3000. API: http://localhost:3001/health.

## Estrutura

- `apps/web`: Next.js PWA
- `apps/api`: Fastify API
- `packages/database`: esquema Prisma

> Sprint 0: fundação inicial. Não utilizar como sistema de emergência em produção.
